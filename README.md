## 🌟 Oyun Özellikleri (Features)

1. **3D Dokunsal ASMR Restorasyon (Tactile Restoration Lab):**
   - Eşyayı 360° parmak veya fare ile döndürme.
   - **⚡ Pas Sökücü Lazer:** Yüzeydeki pası ve kiri anlık kıvılcım efektleriyle temizleme.
   - **🧽 Parlatıcı & Cila:** Yüksek metalik parlaklık ve pürüzsüz ayna etkisi kazandırma.
   - **⚙️ Dişli & Çark:** Mekanik parçaları ve tiktakları onarma.
   - **✨ Altın Varak:** Eşyaya altın işlemeler ekleyerek S-Tier şaheser seviyesine çıkarma.
   - Derecelendirme: **D Tier ➔ C Tier ➔ B Tier ➔ A Tier ➔ S Tier** (Değer 5.5 katına kadar çıkar).

2. **Müşteri Psikolojisi & Canlı Pazarlık (Storefront Bartering):**
   - Dükkana gelen 5 farklı arketip:
     - 🧐 *Lord Harrington (Koleksiyoner)*
     - 🕵️ *Kurnaz Selim (Fırsat Avcısı Eskici)*
     - 👒 *Madame Claire (Antika Meraklısı Turist)*
     - 🕶️ *Don Salvatore (Gece Yarısı Alıcısı)*
     - 👵 *Muazzez Teyze (Nostalji Aşığı)*
   - Gerçek zamanlı sabır barı (Patience Bar), karşı teklifler (`+%15`, `+%30`), eşyanın tarihini anlatma (Provenance) ve satış kapatma.

3. **Depo Savaşları & Gizemli Sandık İhaleleri (Storage Wars Auctions):**
   - 🏚️ *Terk Edilmiş Köy Tavan Arası*
   - 🌾 *Eski Saatçinin Çiftlik Deposu*
   - 🏰 *Mühürlü Konak Mahzeni*
   - Sanal rakiplere karşı geri sayımlı canlı açık artırma heyecanı ve sürpriz eşya kutusu açılışları.

4. **Butik & Küresel İmparatorluk (Tycoon Metagame):**
   - Dükkan Mobilyaları: Kadife Sehpalar, Kristal Avize, Antika Gramofon, Çırak Felix (Otomatik temizleme).
   - Dünya Başkentleri: 🇹🇷 İstanbul (Çukurcuma/Kapalıçarşı), 🇬🇧 Londra (Portobello), 🇯🇵 Tokyo (Yanaka), 🇫🇷 Paris (Saint-Ouen).
   - Müze & Şaheser Koleksiyon Galerisi.

5. **Sıfır Harici Ses Dosyası — Saf Web Audio API:**
   - Lazer vızıltısı, cila sürtünmesi, çark tiktakları, yazar kasa ("Ka-Ching!"), açık artırma tokmağı ve arka planda çalan sıcak lofi caz akorları tamamen tarayıcının yerel ses sentezleyicisiyle üretilir (0 bayt ağ yükü, asla 404 vermez).

## 🚀 Çalıştırma (Quick Start)

```bash
# Bağımlılıkları kur
npm install

# Geliştirme sunucusunu başlat
npm run dev

# Mobil / Web üretim paketini derle
npm run build
```

## 📱 Mobil Uyumluluk
- iOS Safari & Android Chrome için tam ekran, `viewport-fit=cover` güvenli alan (safe-area) desteği.
- Capacitor veya Cordova ile tek komutta yerel iOS (.ipa) ve Android (.apk) paketine dönüştürülebilir.
